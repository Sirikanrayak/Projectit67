# Projectit67 — ระบบติดตามโครงงานนักเรียน

ระบบติดตามโครงงานนักเรียน สาขาวิชาเทคโนโลยีสารสนเทศ วิทยาลัยเทคนิคนครนายก
รันด้วย **Docker Compose**: PHP 8.3 (webdevops/php-nginx) + MySQL 8 + phpMyAdmin

## เทคโนโลยีที่ใช้

- **PHP 8.3** (vanilla, ไม่ใช้เฟรมเวิร์ก) — เว็บเซิร์ฟเวอร์ `webdevops/php-nginx:8.3`
- **MySQL 8.0** — ฐานข้อมูลหลัก, จัดการผ่าน **phpMyAdmin**
- **DataTables** (jQuery) — ตารางค้นหา/เรียง/แบ่งหน้าในทุกหน้ารายการ
- **SweetAlert2** — กล่องแจ้งเตือนและยืนยันการทำรายการทั้งหมด
- **PhpSpreadsheet** / **mPDF** (Composer) — ส่งออกรายงานสรุปโครงงานเป็น Excel/PDF ภาษาไทย (ใช้ฟอนต์ Garuda ที่มากับ mPDF)
- ปุ่มต่าง ๆ ใช้อีโมจิประกอบไอคอน (➕ ✏️ 🗑️ 💾 📎 📅 🔔 ฯลฯ)

## เริ่มต้นใช้งาน

```bash
cp .env.example .env
docker compose up -d --build
docker compose exec web composer install --working-dir=/app   # ติดตั้งไลบรารี PhpSpreadsheet/mPDF (ครั้งแรกเท่านั้น)
```

เปิดใช้งานได้ที่:

| บริการ      | URL                     | หมายเหตุ |
|-------------|-------------------------|----------|
| เว็บแอป      | http://localhost:8080   | หน้าเข้าสู่ระบบ |
| phpMyAdmin  | http://localhost:8081   | เชื่อมต่อ MySQL อัตโนมัติ (host: `db`) |
| MySQL       | localhost:3306          | ใช้ค่าจาก `.env` |

ฐานข้อมูลและตารางทั้งหมดถูกสร้างอัตโนมัติจาก [`db/init/01_schema.sql`](db/init/01_schema.sql) เมื่อสร้างคอนเทนเนอร์ MySQL ครั้งแรก
และระบบจะสร้างบัญชีผู้ใช้เริ่มต้น + โครงงานตัวอย่างให้อัตโนมัติในการเรียกหน้าเว็บครั้งแรก (ดู [`app/includes/seed.php`](app/includes/seed.php))

## ฟีเจอร์

- **ระบบสมาชิก**: สมัคร/เข้าสู่ระบบ 3 บทบาท (ผู้ดูแลระบบ / ครูที่ปรึกษา / นักเรียน) พร้อมอนุมัติบัญชีก่อนใช้งาน — หน้าเข้าสู่ระบบแบบแบ่งครึ่งซ้าย/ขวา มีแท็บนักเรียน (เข้าด้วยรหัสนักเรียน) / บุคลากร (เข้าด้วยอีเมล) ในช่องเดียวกัน พร้อม "จำฉันไว้" (คุกกี้ 30 วัน)
- **จัดการโครงงาน**: เพิ่ม/แก้ไข/ลบ, เช็กลิสต์ 9 ขั้นตอน, บันทึกความคืบหน้ารายวัน
- **ครูผู้สอนโครงงาน**: มอบหมายให้บัญชีครูที่ปรึกษาเดิมเป็น "ครูผู้สอน" ของระดับชั้น/กลุ่มเรียนหนึ่ง ๆ ได้ (ตั้งค่าที่หน้าจัดการผู้ใช้) — ให้สิทธิ์เพิ่ม/แก้ไข/ลบโครงงานทุกชิ้นในระดับชั้น/กลุ่มเรียนนั้น ไม่ว่าจะเป็นครูที่ปรึกษาของโครงงานนั้นเองหรือไม่
- **แนบไฟล์**: อัปโหลด/ดาวน์โหลด/ลบไฟล์ต่อโครงงาน (เก็บนอก webroot เพื่อความปลอดภัย, จำกัดขนาด/จำนวนไฟล์)
- **ให้คะแนน/ประเมินผล**: เกณฑ์ 4 ด้าน รวม 100 คะแนน คำนวณเกรดอัตโนมัติ (ครูที่ปรึกษา/ผู้ดูแลระบบเท่านั้น)
- **กำกับคุณภาพโครงงานด้านเทคโนโลยีสารสนเทศ**: เช็กลิสต์ 7 ขั้นตอนตามแบบฟอร์มของวิทยาลัย (ยื่นหัวข้อ, ตรวจ 3 บทแรก, สอบหัวข้อ, ตรวจความคืบหน้า, ขึ้นสอบ, ส่งรูปเล่ม) — 2 ขั้นตอนต้องผ่านทั้งครูที่ปรึกษาและครูผู้สอนโครงงานด้านเทคโนโลยีสารสนเทศแยกกัน พร้อมชื่อผู้เซ็นและวันที่ หากยังไม่ผ่านครบทุกขั้นตอน ระบบจะระงับการออกผลการประเมิน (ยกเว้นผู้ดูแลระบบ)
- **เสนอชื่อโครงงาน**: นักเรียนเสนอหัวข้อที่สนใจได้สูงสุด 7 หัวข้อ (พร้อมวิธีศึกษา/ผลที่คาดว่าจะได้รับ) ครูที่เป็นครูผู้สอนของระดับชั้น/กลุ่มเรียนนั้น (หรือผู้ดูแลระบบ) พิจารณาอนุมัติหัวข้อใดหัวข้อหนึ่งเพื่อสร้างเป็นโครงงานจริงโดยอัตโนมัติ หรือปฏิเสธพร้อมข้อเสนอแนะให้เสนอใหม่
- **รายงานความก้าวหน้า (รอบทางการ)**: รายงานความก้าวหน้า 3 รอบตามแบบฟอร์มของวิทยาลัย — สมาชิกโครงงานกรอกแผนงาน/ปริมาณงานที่ส่ง ครูที่ปรึกษาหรือครูผู้สอนให้ผลการประเมิน (ดี/พอใช้/ปรับปรุง) จากนั้นครูที่ปรึกษากด "ขอเสนอสอบโครงงาน" เมื่อโครงงานเสร็จสมบูรณ์ พร้อมช่องความเห็นของครูผู้สอนโครงงานด้านเทคโนโลยีสารสนเทศ
- **แสดงผลงานของนักเรียน**: หน้าสาธารณะ (ไม่ต้องเข้าสู่ระบบ) แสดงผลงานโครงงานแยกตามระดับชั้น พร้อมรูปภาพ ลิงก์ผลงาน และคำอธิบาย (ไม่เกิน 500 คำ) — ครูที่ปรึกษา/ครูผู้สอน/ผู้ดูแลระบบเลือกเปิดแสดงเป็นรายโครงงานที่หน้ารายละเอียดโครงงาน
- **ปฏิทิน/ไทม์ไลน์**: ปฏิทินรายเดือนแสดงวันเริ่ม/กำหนดส่ง พร้อมไทม์ไลน์ความคืบหน้า
- **แจ้งเตือนกำหนดส่ง**: ไอคอนกระดิ่งแสดงโครงงานที่ใกล้ถึง/เลยกำหนดภายใน 7 วัน
- **แดชบอร์ด**: สถิติภาพรวม, กราฟความคืบหน้า, ขั้นตอนปัจจุบันของแต่ละโครงงาน
- **จัดการผู้ใช้ (ผู้ดูแลระบบ)**: อนุมัติ/ระงับ/ลบ/แก้ไขผู้ใช้, เปิด-ปิดการอนุมัติผู้สมัครใหม่
- **สรุปครูที่ปรึกษา**: จำนวนโครงงาน/ความคืบหน้าเฉลี่ยต่อครูที่ปรึกษาแต่ละคน
- **ส่งออก/นำเข้าข้อมูล**: ส่งออก CSV, สำรอง/นำเข้าข้อมูลเป็น JSON (ผู้ดูแลระบบ)
- **สรุปโครงงาน (Excel/PDF)**: รายงานสรุปโครงงานตามระดับชั้น/กลุ่มเรียน รูปแบบตรงตามแบบฟอร์ม "แบบรายงานโครงงานวิชาชีพ" ของวิทยาลัย พร้อมส่งออกเป็นไฟล์ Excel (.xlsx) และ PDF ภาษาไทย (สำหรับผู้ดูแลระบบและครูผู้สอนโครงงาน)
- **ตั้งค่าระบบ (ผู้ดูแลระบบ)**: เปลี่ยนชื่อระบบ, ชื่อหน่วยงาน, ข้อความท้ายหน้าเว็บ, อัปโหลด/ลบโลโก้ระบบ
- **โหมดกลางวัน/กลางคืน**: ปุ่มสลับธีมมุมขวาบนทุกหน้า (รวมหน้าเข้าสู่ระบบ) จำค่าไว้ต่อเบราว์เซอร์

## โครงสร้างโปรเจกต์

```
docker-compose.yml       กำหนดคอนเทนเนอร์ web / db / phpmyadmin
db/init/01_schema.sql    โครงสร้างฐานข้อมูล (รันอัตโนมัติครั้งแรก)
app/
  composer.json/lock     ไลบรารี PHP (PhpSpreadsheet, mPDF) — รัน `composer install` เพื่อสร้าง vendor/ (ไม่ commit เข้า git)
  includes/              โค้ดฝั่งเซิร์ฟเวอร์ที่ไม่เปิดผ่านเว็บ (อยู่นอก public/)
    config.php           เชื่อมต่อฐานข้อมูล (PDO)
    seed.php             สร้างบัญชี/ข้อมูลตัวอย่างเมื่อฐานข้อมูลว่าง + migration ฟังก์ชัน ensure_*()
    auth.php             ระบบล็อกอิน/สิทธิ์/CSRF
    helpers.php          ฟังก์ชันช่วยเหลือ, ค่าคงที่ (ขั้นตอน, เกณฑ์คะแนน ฯลฯ)
    project_repo.php     ชั้นเข้าถึงข้อมูลโครงงาน + ตรวจสิทธิ์ (รวมสิทธิ์ครูผู้สอนโครงงาน)
    layout/               ส่วนหัว/นำทาง/ท้ายหน้าที่ใช้ร่วมกันทุกหน้า
  public/                 เว็บรูท (WEB_DOCUMENT_ROOT)
    *.php                 แต่ละหน้า/ตัวจัดการฟอร์มของระบบ
    project_summary.php          หน้ารายงานสรุปโครงงานตามระดับชั้น/กลุ่มเรียน
    project_summary_export.php   ส่งออกรายงานสรุปโครงงานเป็น Excel/PDF
    showcase.php                 หน้าแสดงผลงานของนักเรียน (สาธารณะ ไม่ต้องเข้าสู่ระบบ)
    project_showcase_update.php  บันทึกการเปิด/ปิดแสดงผลงาน รูปภาพ ลิงก์ คำอธิบาย ต่อโครงงาน
    assets/css, assets/js CSS และ JavaScript
    assets/branding/      โลโก้ระบบที่ผู้ดูแลระบบอัปโหลด (public, ตั้งค่าได้ที่หน้า "ตั้งค่าระบบ")
    assets/showcase/      รูปภาพผลงานที่แสดงในหน้า "แสดงผลงานของนักเรียน" (public)
  storage/uploads/         ไฟล์แนบที่อัปโหลด (อยู่นอก webroot, ให้บริการผ่าน file_download.php เท่านั้น)
  storage/tmp/mpdf/        ไฟล์ชั่วคราวของ mPDF ตอนสร้าง PDF (อยู่นอก webroot)
```

## คำสั่งที่ใช้บ่อย

```bash
docker compose logs -f web        # ดู log ของ PHP/Nginx
docker compose exec db mysql -u root -p projectit67   # เข้า MySQL CLI
docker compose down               # หยุดการทำงาน
docker compose down -v            # หยุดและลบข้อมูลฐานข้อมูลทั้งหมด
```
